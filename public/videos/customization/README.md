# Customization Videos Directory

Place your high-definition MP4 videos for the **"YOUR PRODUCT. YOUR RULES."** scroll-driven storytelling section in this folder:

1. `01-embroidery.mp4` — Embroidery machinery / close-up stitch video
2. `02-dtf-printing.mp4` — Direct-to-Film printing / transfer heat-press video
3. `03-dtg-printing.mp4` — Direct-to-Garment textile digital print video
4. `04-rhinestones.mp4` — Rhinestone, glass crystal, and metallic embellishments video
5. `05-labels-tags.mp4` — Woven neck labels, hem tags, and debossed hangtags video
6. `06-packaging.mp4` — Frosted zip polybag unboxing and luxury presentation packaging video

> **Note**: If a video file is not present or is loading, the system automatically crossfades using the high-resolution editorial poster photograph configured in `src/data/customizationStoryData.js`.
